# MNIST 手写数字识别 · 深度学习原理入门项目

用 PyTorch 从零训练一个手写数字识别模型（0~9），适合给非算法背景的同事讲清楚：
**深度学习模型是什么、怎么学会的、学完之后能做什么**。

本项目自带两种模型、一个边讲边跑的 Notebook、一个鼠标手写实时识别的演示，
以及训练好的模型和全套讲解图表，分享当天开箱即用。

---

## 二、快速开始

### 第 1 步：安装环境（只需一次）

双击 `setup.bat`，会自动：

1. 创建虚拟环境 `.venv`（Python 3.12）
2. 安装 PyTorch CPU 版（约 200MB，视网速需要几分钟）
3. 安装其他依赖（matplotlib、gradio、jupyter 等）

> 注意：这台机器的系统 `python` 命令被旧版 Python 2.7 占用，
> 所以安装脚本固定使用 `py -3` 启动 Python 3.12，其他电脑也可以正常使用。

### 第 2 步：训练模型

双击 `train.bat`（默认训练 CNN），或在命令行执行：

```bat
python -m src.train --model mlp --epochs 8   :: 训练全连接网络
python -m src.train --model cnn --epochs 8   :: 训练卷积网络
```

训练 8 个 epoch 后，模型文件保存在 `outputs/`。训练默认开启数据增强
（随机旋转/平移/缩放），让模型更适应手写风格差异。本项目已经预训练好两个模型：

| 模型 | 测试准确率 | 参数量 |
| --- | --- | --- |
| MLP（全连接） | 97.72% | 10.2 万 |
| CNN（卷积，数据增强） | 98.95% | 42.2 万 |

### 第 3 步：生成讲解图表

双击 `evaluate.bat`，或执行：

```bat
python -m src.evaluate --model mlp
python -m src.evaluate --model cnn
```

会生成：训练损失/准确率曲线、混淆矩阵、错误样例、MLP 权重模板、CNN 卷积核和特征图。
另外还会自动更新演示页的 0~9 示例图，并生成一组“挑战题”
（模型会认错的疑难样本）。全部保存在 `outputs/` 目录。

### 第 4 步：打开手写识别演示

双击 `run_demo.bat`，浏览器会自动打开一个画板，用鼠标写数字，模型实时识别：

页面布局：左侧是 420x420 的大画板（可点“随机示例”一键体验）；右侧实时显示
识别结果大数字、0~9 每个数字的概率条形图，以及“模型看到的 28×28 预处理图”
（讲原理时非常直观）；底部有 0~9 的示例图，还有一组“挑战题”——
模型会认错的疑难样本，点击识别后页面会揭晓正确答案，非常适合讲模型的盲区。
页面下方还有“CNN 是怎么算出来的”**小白版动画**，完整演示：
**看 → 找模板 → 组合 → 压缩 → 投票打分 → 出结果**。输入 28×28 → 卷积层 1
（32 张特征图）→ 卷积层 2（64 张）→ 池化（64 张 7×7）→ **全连接层给 0~9 各打一个分**
（正分支持、负分反对）→ 输出概率；最下面是“为什么判断是 X”的 Grad-CAM 证据图，
用高亮标出模型重点看的区域。特征图都是模型真实的中间计算，把“黑盒”直接摊开给同事看。

```bat
python app/demo.py            :: 本机演示
python app/demo.py --share    :: 生成公网链接，同事可以用手机/其他电脑远程体验
```

### 第 5 步：讲解 Notebook

在项目根目录启动 Jupyter，打开 `notebooks/01_原理讲解.ipynb`，从头到尾执行一遍：

```bat
jupyter notebook
```

Notebook 覆盖：数据长什么样 → 神经元原理 → MLP → 训练四步（前向/损失/反向/更新）
→ 混淆矩阵 → 打开黑盒看权重 → CNN 卷积核与特征图 → 制造场景延伸。

## 三、讲解建议（90~120 分钟）

1. **直观认识（15 分钟）**：展示 28x28 像素、灰度值，让同事明白“图 = 数字表格”
2. **神经元与 MLP（40 分钟）**：加权求和 + 激活函数；训练 = 反复微调“旋钮”减少错误
3. **CNN（30 分钟）**：为什么拉平成一条线会丢失空间关系；卷积核 = 自动学习的笔画模板
4. **演示与互动（30 分钟）**：现场手写识别、挑战题（让模型翻车）、
   混淆矩阵、分析错误样例

## 四、常见问题

**Q：下载 MNIST 很慢或失败？**
数据集已经下载并保存在 `data/` 目录，分享当天断网也能跑。
如果换了电脑，也可以手动下载四个文件放入 `data/MNIST/raw/`。

**Q：没有显卡能跑吗？**
可以。MNIST 很小，本项目全部代码在普通 CPU 上运行，训练只需几分钟。

**Q：双击 .bat 一闪而过？**
在 `setup.bat` / `train.bat` 所在文件夹上右键 → 用 PowerShell 或 CMD 打开，
手动执行查看报错信息。

**Q：演示报 `Sketchpad() got an unexpected keyword argument 'shape'`？**
这是 Gradio 新老版本参数差异导致的。`app/demo.py` 已做自动兼容
（新版本用 `height/width + Brush`，旧版本用 `shape/brush_radius`），
重新双击 `run_demo.bat` 即可。

**Q：为什么第一次写数字没有反应，第二次才有？**
Gradio 首次交互时队列和画板组件需要初始化，偶尔第一次落笔的事件没有带出有效笔画。
项目已做三项处理：启动时自动预热（第一次识别也会立即出结果）、预启动处理队列、
画板旁新增「🔍 识别」按钮兜底。如果某次写完没反应，直接点「识别」即可。

**Q：运行时报 `OpenBLAS error` 或提示内存不足？**
项目脚本已自动限制数值库线程数来节省内存。若仍报错，先关闭几个占用内存的
程序（浏览器标签页、IDE 等），再重新运行。

**Q：手写数字为什么偶尔会识别错？**
MNIST 里的数字是居中、较粗的规范笔画，鼠标写得太细、太偏、太斜都会影响准确率。
项目已自动做预处理：裁出数字、**保持宽高比缩放**（细长的 1 不会被拉变形，
6 的开口也不会被堵上）、对比度增强、按笔画质心居中，并用数据增强训练模型。
演示时写大、写粗、写中间效果最好；置信度低于 40% 时界面会提示重写。

## 五、从手写数字到制造场景

| 本项目 | 制造场景的对应 |
| --- | --- |
| 手写数字 0~9 分类 | 产品表面缺陷分类（良品/划痕/污渍/破损） |
| 28x28 灰度图 | 工业相机图像（需统一尺寸和打光） |
| 6 万张带标签数据 | 采集 + 人工标注的缺陷样本 |
| 测试集准确率 | 上线验收指标（漏检率/误报率） |
| 混淆矩阵 | 发现易混缺陷类型，针对性补数据 |

核心结论：**深度学习模型的原理是通用的，决定落地效果的是数据质量、标注规范和验证体系。**
